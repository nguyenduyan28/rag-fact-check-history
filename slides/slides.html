Thiết lập thực nghiệm

5 cấu hình so sánh + oracle

  • LLM-only (không truy xuất)
  • BM25 · Dense (BGE-M3) · Hybrid — top-5
  • Facet Graph RAG (5 văn bản + 3 đồ thị)
  • Oracle: bằng chứng vàng — chẩn đoán trần
Cùng tập câu, cùng bộ kiểm chứng (Gemini 2.5 Flash, temperature 0), cùng cách trình bày bằng chứng → khác biệt quy về nguồn bằng chứng

Tiêu chí

  • Truy xuất: tỷ lệ bao phủ bằng chứng vàng (hit rate)
  • Phân loại: accuracy, macro F1, recall từng nhãn, kiểm định McNemar cho so sánh cặp
  • Giải thích: chỉ số cấu trúc + phân tích định tính
Nguyên tắc: trường sinh dữ liệu (tri thức gốc, nhãn, bằng chứng vàng) không bao giờ vào truy vấn hay prompt
